# GP-17 Payments and invoices

**Kind.** Gap (requirements audit, 23 October 2026).

`payments` has no direction (client to AMPM vs AMPM to vendor), no payer or payee and no method. `contracts / invoices` has a single amount with no client/internal split. If AMPM invoices marked-up vendor services, this is a margin-leak path that the §4 security note is meant to prevent.

## How the design resolved it

`payments.direction`, `invoices.direction` (data model §20.2)
