# GP-41 Aadhaar

**Kind.** Gap (requirements audit, 23 October 2026).

The Aadhaar framework restricts private storage and use of Aadhaar numbers. Recommended position: never store Aadhaar numbers. If hotels need identity for check-in, store the minimum (document type and a masked reference) under restricted access with automatic deletion after checkout.

## How the design resolved it

`identity_documents.document_type` excludes Aadhaar (A-8) (data model §20.2)
