# GP-31 Authentication specifics

**Kind.** Gap (requirements audit, 23 October 2026).

No sign-in method for clients (email and password vs phone OTP, which is common in India), no password reset or account recovery flow (PORTAL-FLOW offers only "Contact AMPM for access help"), no multi-factor authentication for staff who can see every client's finances, no session or timeout policy.

## How the design resolved it

`users` auth fields, `auth_tokens` (A-13) (data model §20.2)
