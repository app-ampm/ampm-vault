# Client portal on the web as well as the apps

**What we need.** AMPM asked for iOS and Android apps. Whether the client portal also needs a web version, for example for reviewing designs on a laptop, is not stated. A React Native Web build from the same code would provide it.

**Why it matters.** Adds or removes a web build from the estimate.

**Linked questions.** [[Q01 Delivery platform]]

## Answer

**Answered 26 October 2026**: yes, the client portals also run in the browser; both apps support iPad and Android tablets; a client is verified by both email and mobile. Recorded in docs/decisions.json (Q1, Q13, A-1, T-1, W-3, A-13, T-6, U-9).
