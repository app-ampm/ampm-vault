Both tools are MCP servers in `.mcp.json`; `CLAUDE.md` holds the rules sessions follow.

**Found and decided during the session.** MemPalace's shell hooks in the user's global settings filed a running session under the shared wing `wing_api` and, because drawers are keyed by content and upserted, overwrote the wing the project hooks set (all 243 drawers of this session were in `wing_api`).
