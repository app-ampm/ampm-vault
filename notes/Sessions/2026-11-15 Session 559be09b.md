## Narrative

A side session started from the enquiry-pipeline session (D-130/D-131) to unblock the last step of the client hotel workflow. An enquiry could never reach `confirmed`: the AC-05.6 guard needs a done `contract_signed` milestone carrying a document, and nothing in the app could upload one. The API also accepted any client-supplied UUID as `documentId`.

**Decided ([[D-132 Signed contracts attach to a contract_signed milestone through a minimal documents service]]):**
- Build the smallest compliant slice of Module N documents rather than an interim. The `documents` and `document_access_links` tables already existed.
- The signed contract attaches through its milestone, so access follows the owning record.
- Links are `document_access_links` rows: hashed token, 15 minutes, 5 downloads, audited.
- `documentId` is no longer a request field.
- A `contract_signed` milestone cannot be marked done until a contract is attached, because a done milestone is read-only and would strand the enquiry.

**Built** on branch `feat/milestone-signed-contract`, cut from origin/main `58ac4c8`:
- **API:** a new `documents` module (content sniffing for PDF/JPEG/PNG, a 20 MB ceiling, the shared stub AV scan moved to `storage/`, store-then-transaction with byte cleanup, a minted link, a public link route with a CAS download cap). `MilestoneContractService` adds `POST …/:id/contract` and `POST …/:id/contract/link`. The transition guard is added and the raw-body gate is widened.
- **Mobile Booking tab:** Attach, Replace and View contract on `contract_signed` milestones, with Done hidden until a contract is attached. `pickMediaFile` moved to `@ampm/ui` as `pickFile`.
- **Tests:** a new e2e suite (7 cases), the confirm-guard e2e now uploads a real PDF, a unit spec for the content rules, mobile tests (7 cases) and a `pickFile` web test.

**Remaining:**
- Deploy needs a full API-first redeploy (new endpoints plus a request-contract change, no migration).
- Per-type and config-driven size limits and a real AV scanner are still to build, as for media.
- Client visibility of the contract (§5.14 "set client visibility") is still to build.
- A native file picker is still to build; native shows a "use the web workspace" toast.
