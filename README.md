# AMPM vault

Obsidian vault for the AMPM platform project. Open this folder in Obsidian and start at [[Home]].

The decision, assumption and finding notes, the `docs/` copy and `reference_docs/` are generated or synced from the project repository, [ampm-platform](https://github.com/app-ampm/ampm-platform), by `docs/tools/vault_sync.py` there. Edit the documents in that repository, and write your own notes here: open items, the log and anything you add are kept and committed automatically.
